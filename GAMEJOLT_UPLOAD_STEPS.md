# GameJolt Upload Steps

I cannot press the final upload/publish button without an authenticated GameJolt connector or browser session, but this folder includes a ready ZIP and page text.

## Upload

1. Open GameJolt:

```text
https://gamejolt.com/dashboard/games/add
```

2. Create a new game page.
3. Use the text from `GAMEJOLT_PAGE.md`.
4. Create a new release/package.
5. Choose a downloadable Windows build.
6. Upload:

```text
C:\Users\Jerry\Downloads\GameJolt_Undertale_Mod_Menu_ProMax_202605071820.zip
```

7. Set the launch file to:

```text
UndertaleSaveStudioPro.exe
```

8. Publish the package, release, and game page.

- Price: Free

- Platform: Windows
